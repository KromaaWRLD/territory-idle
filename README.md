# Territory Idle

An idle territorial conquest game mixing the best of **State.io**, **FrontWars**, and **Territorial.io**.

Expand your empire, generate troops passively, conquer neighboring lands, outsmart AI factions, and dominate the map — even while you're away!

## How to Play

1. Open `index.html` in any modern browser (or host it).
2. You start with a small territory. Troops generate automatically over time.
3. Click one of your territories to select it, then click an adjacent enemy/neutral territory to attack.
4. Use the attack % slider to decide how many troops to send.
5. Upgrade production, strength, and unlock idle features.
6. Progress is saved automatically in your browser.

## Features

- **Idle troop generation** based on controlled land + upgrades
- **AI opponents** that expand and fight back
- **Offline progress** (calculated when you return)
- **Upgrade system** for production speed, troop power, max attack %, etc.
- **Prestige / prestige points** for long-term progression
- Clean modern UI with canvas map
- Fully client-side — no server needed

## Controls

- **Left Click** on your territory → Select
- **Left Click** on target → Attack with current %
- **Slider** → Change attack percentage
- **Buttons** → Buy upgrades, prestige, etc.

Enjoy conquering the world at your own pace!
